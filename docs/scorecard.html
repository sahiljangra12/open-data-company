Load Forecast Scorecard: PJM, summer

How to read this

Why normalized actuals

PJM's forecast assumes normal weather. Comparing it with the raw metered peak would mostly measure how hot the summer was, so the error uses PJM's weather-normalized peak. The metered peak is shown for reference.

What the error means

Error = (forecast − normalized actual) ÷ normalized actual. Positive means the forecast was too high.

What the revision means

The last column compares what two consecutive reports said about the same future summer. A large negative number means expected growth was pushed back or cut.

Limits: this preview covers one forecast year at a one-year horizon, so it cannot show whether any zone is consistently over- or under-forecast. Both the forecast and the normalized actual come from PJM, so normalization choices are PJM's own. Earlier years and longer horizons are being added.
