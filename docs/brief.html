Daily brief

Each day, after the data is refreshed, the Data Agent reads what changed, checks the newest figures in the datasets and writes this short note. It runs on GitHub, with tools written for this site.

27 November 2026, 00:31 UTC

10 datasets changed in the latest check

What changed

  • Earthquakes, past 30 days: 19 rows added, 11 values revised. For example, 55 km NE of Valmy, Nevada, 2026-11-26 22:40 UTC: Magnitude 2.9.
  • Research papers published each year, worldwide: 20 values revised. For example, 2025-01-01: Scholarly records registered with Crossref, by year published 9,983,959.
  • Biodiversity records by year observed (GBIF): 360 values revised. For example, 2025-01-01: Records of living things, by year observed (GBIF) 307,412,800.
  • Biodiversity records by country (GBIF): 223 values revised. For example, Argentina, 2026: Records of living things located in the country (GBIF) 16,468,910.
  • Birds seen each day: eBird checklists and species: 1 rows added, 14 values revised. For example, 2026-11-24: Bird checklists sent in from the United States that day 14,211.
  • US electricity demand by grid operator, daily: 1 rows added, 8 values revised. For example, 2026-11-24: Electricity demand in the lower 48 states, daily 11,455,100.

Written from the change log alone; the model's draft did not pass the figure check.

Written by the change log alone (no model was reachable). Tools it called: none. Before publishing, each figure in the note is matched against what the tools returned; a note that fails is replaced by a plain summary of the change log. A small model can still word things loosely, so check a figure in the datasets or the change log before you cite it.

Ask the agent yourself

The same agent answers questions posted as GitHub issues, usually within about ten minutes, with the figures, their years and their sources. For instant answers in the browser, use Data AI.
